LENJA INTERNATIONAL HANDICRAFT - DARAZ INSPIRED DEMO

Features added:
- Daraz-inspired orange storefront layout with search, categories, flash sale and product cards.
- Customer and Admin role-based login using browser localStorage.
- Logout option shown after login.
- Customer dashboard is protected and shows customer options.
- Admin panel is protected for admin users only.
- Admin can ADD, EDIT and REMOVE products.
- Product changes are immediately reflected on the storefront.
- Shopping cart uses localStorage.
